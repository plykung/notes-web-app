# Tags live in the note text, not in Graph categories

Notes are grouped by Tags, which are `#word` tokens written in the note text (Thai letters allowed). The Graph `categories` field is deliberately left unused. Because Tags are plain text, the native Sticky Notes app on the PC can find them with its own search, even though it has no category UI. Using both Tags and categories would create two lists that drift apart, so Tags are the only one.
