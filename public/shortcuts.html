ทางลัดและ Siri

เปิดโน้ตได้เร็วขึ้นจากหน้าจอโฮม ปุ่ม Action หรือ Siri

ลิงก์ด้านล่างเปิดแอปโน้ตและทำงานหนึ่งอย่าง ลิงก์จะไม่บันทึกหรือลบสิ่งใดเอง โน้ตที่เปิดจากลิงก์จะบันทึกเมื่อคุณพิมพ์หรือปิดโน้ตเท่านั้น

Android: กดค้างที่ไอคอนแอปโน้ตเพื่อดูทางลัด New note, Latest note และ Search และใช้ “แชร์” จากแอปอื่นเพื่อส่งข้อความ ลิงก์ หรือรูปภาพมาเป็นโน้ตใหม่ หน้านี้มีไว้สำหรับ iPhone และ iPad ซึ่งใช้แอปคำสั่งลัด (Shortcuts) แทน

เพิ่มด้วยการแตะครั้งเดียว

แตะปุ่มด้านล่างบน iPhone หรือ iPad แล้วแตะ “รับคำสั่งลัด”

โน้ตใหม่ โน้ตใหม่ด้วยเสียง โน้ตล่าสุด ค้นหาโน้ต

ลิงก์ใช้ไม่ได้? แจ้งได้ที่ notes (at) naphats (dot) me

ลิงก์ที่ใช้ได้

  • โน้ตใหม่
  • โน้ตใหม่พร้อมแท็กและสี
  • โน้ตล่าสุด (รีเฟรชก่อน)
  • ค้นหา

สีที่ใช้ได้: yellow, green, pink, purple, blue, gray, charcoal

1. “โน้ตใหม่” ด้วยการพูดกับ Siri

  1. เปิดแอป คำสั่งลัด (Shortcuts) แล้วแตะ +
  2. เพิ่มคำสั่ง Dictate Text (ป้อนข้อความตามคำบอก)
  3. เพิ่มคำสั่ง URL Encode (เข้ารหัส URL) โดยใช้ผลจากขั้นที่แล้ว
  4. เพิ่มคำสั่ง Text (ข้อความ) แล้วพิมพ์ลิงก์ด้านล่าง ตามด้วยผลของ URL Encode
  5. เพิ่มคำสั่ง Open URLs (เปิด URL)
  6. ตั้งชื่อคำสั่งลัดว่า New note แล้วพูดว่า “หวัดดี Siri, New note”

ชื่อคำสั่งในเครื่องของคุณอาจแสดงเป็นภาษาไทย ให้ค้นหาด้วยชื่อในวงเล็บ

2. “โน้ตล่าสุด” และ “ค้นหา”

  • โน้ตล่าสุด: สร้างคำสั่งลัดที่มีเพียง Open URLs พร้อมลิงก์โน้ตล่าสุด
  • ค้นหาคำ: ใช้ Ask for Input (ขออินพุต) → URL Encode → ข้อความ ตามด้วยผล → Open URLs

3. ใส่ไว้ที่ไหนดี

  • หน้าจอโฮม: ในแอปคำสั่งลัด แตะ ⓘ ของคำสั่งลัด แล้วเลือก เพิ่มไปยังหน้าจอโฮม
  • ปุ่ม Action (iPhone 15 Pro ขึ้นไป): การตั้งค่า → ปุ่ม Action → คำสั่งลัด → เลือกคำสั่งลัดของคุณ
  • แตะด้านหลัง: การตั้งค่า → การช่วยการเข้าถึง → การสัมผัส → แตะด้านหลัง

ลิงก์อาจเปิดใน Safari แทนแอปที่ติดตั้งไว้ ขึ้นอยู่กับเวอร์ชัน iOS ทั้งสองแบบใช้โน้ตชุดเดียวกัน แต่ต้องลงชื่อเข้าใช้ในแต่ละที่

Shortcuts & Siri

Open Notes faster from your home screen, the Action Button or Siri.

The links below open Notes and do one thing. A link never saves or deletes anything by itself: a note it opens is saved only once you type in it or close it.

Android: long-press the Notes icon for the New note, Latest note and Search shortcuts, and use Share in any app to send text, a link or photos to a new note. This page is for iPhone and iPad, which use the Shortcuts app instead.

Add in one tap

Tap a button on your iPhone or iPad, then tap “Get Shortcut”.

Colours: yellow, green, pink, purple, blue, gray, charcoal.

1. “New note” by talking to Siri

  1. Open the Shortcuts app and tap +.
  2. Add Dictate Text.
  3. Add URL Encode, using the dictated text.
  4. Add Text: type the link below, then insert the URL Encode result after it.
  5. Add Open URLs.
  6. Name the shortcut New note, then say “Hey Siri, New note”.

2. “Latest note” and “Search”

  • Latest note: a shortcut with just Open URLs and the latest-note link.
  • Search for words: Ask for Input → URL Encode → Text followed by the result → Open URLs.

3. Where to put them

  • Home screen: in Shortcuts, tap the shortcut's ⓘ, then Add to Home Screen.
  • Action Button (iPhone 15 Pro and later): Settings → Action Button → Shortcut → pick yours.
  • Back Tap: Settings → Accessibility → Touch → Back Tap.

Depending on the iOS version, a link may open in Safari rather than the installed app. Both show the same notes, but each needs you to sign in.
