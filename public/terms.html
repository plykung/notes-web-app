ข้อกำหนดการใช้งาน

มีผลตั้งแต่วันที่ 26 ตุลาคม 2569

ข้อกำหนดนี้ใช้กับการใช้งานแอป Notes (“แอป”) ซึ่งพัฒนาและดูแลโดยบุคคลธรรมดา (“ผู้พัฒนา”, “เรา”) เมื่อคุณใช้แอป ถือว่าคุณยอมรับข้อกำหนดนี้และนโยบายความเป็นส่วนตัว หากไม่ยอมรับ โปรดหยุดใช้แอป

1. แอปนี้คืออะไร

แอปช่วยให้คุณอ่านและแก้ไขโน้ตใน Microsoft Sticky Notes ของคุณเองผ่านเบราว์เซอร์บน PC, iPad และโทรศัพท์ รวมถึงขณะออฟไลน์ แอปเชื่อมต่อกับบริการของ Microsoft โดยใช้บัญชี Microsoft ของคุณ

แอปนี้ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรอง และไม่ได้รับการสนับสนุนจาก Microsoft Microsoft, Sticky Notes, Outlook และ OneNote เป็นเครื่องหมายการค้าของ Microsoft Corporation

2. บัญชีและการใช้บริการของ Microsoft

คุณต้องมีบัญชี Microsoft และต้องปฏิบัติตามข้อตกลงการให้บริการของ Microsoft คุณรับผิดชอบต่อความปลอดภัยของบัญชีและอุปกรณ์ของคุณ และต่อทุกกิจกรรมที่เกิดขึ้นผ่านบัญชีของคุณ

3. การใช้งานที่เหมาะสม

  • ใช้แอปกับโน้ตของคุณเองเท่านั้น และไม่พยายามเข้าถึงบัญชีของผู้อื่น
  • ไม่ใช้แอปเพื่อกระทำการที่ผิดกฎหมาย หรือละเมิดสิทธิของผู้อื่น
  • ไม่พยายามรบกวน ดัดแปลง หรือหลีกเลี่ยงมาตรการความปลอดภัยของแอปหรือบริการของ Microsoft

4. เนื้อหาของคุณ

โน้ตเป็นของคุณ เราไม่อ้างสิทธิ์ใด ๆ และไม่ได้เข้าถึงเนื้อหาของคุณ คุณเป็นผู้รับผิดชอบต่อเนื้อหาที่คุณบันทึก รวมถึงข้อมูลส่วนบุคคลของผู้อื่น และการปฏิบัติตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 และกฎหมายอื่นที่เกี่ยวข้อง

5. ข้อจำกัดของแอป

แอปอาศัยวิธีการทำงานของบริการ Microsoft บางส่วนที่ Microsoft ไม่ได้รับรองไว้อย่างเป็นทางการ ซึ่งอาจเปลี่ยนแปลงได้โดยไม่แจ้งล่วงหน้า สิ่งที่ควรทราบ:

  • การแก้ไขโน้ตในแอปจะสร้างโน้ตฉบับใหม่แทนฉบับเดิม หน้าต่าง Sticky Notes ที่เปิดอยู่บน PC อาจปิดและเปิดใหม่
  • สี การปักหมุด และวันที่สร้างดั้งเดิม ทำงานเต็มรูปแบบเฉพาะในแอปนี้ ช่องว่างหลายตัวที่พิมพ์ในแอป Sticky Notes บน PC อาจเหลือช่องเดียว
  • การเปลี่ยนแปลงที่ทำขณะออฟไลน์อาจขัดแย้งกับการเปลี่ยนแปลงจากอุปกรณ์อื่น แอปจะให้คุณเลือกฉบับที่ต้องการเก็บ

6. การไม่รับประกัน

แอปให้บริการ “ตามสภาพที่เป็นอยู่” และ “ตามที่มีให้บริการ” โดยไม่มีการรับประกันใด ๆ ไม่ว่าโดยชัดแจ้งหรือโดยปริยาย รวมถึงการรับประกันว่าแอปจะทำงานได้ต่อเนื่อง ไม่มีข้อผิดพลาด หรือข้อมูลจะไม่สูญหาย โปรดสำรองข้อมูลสำคัญไว้เสมอ

7. การจำกัดความรับผิด

เท่าที่กฎหมายไทยอนุญาต ผู้พัฒนาจะไม่รับผิดต่อความเสียหายทางอ้อม ความเสียหายพิเศษ ความเสียหายต่อเนื่อง หรือการสูญหายของข้อมูล รายได้ หรือโอกาสทางธุรกิจ ที่เกิดจากการใช้หรือไม่สามารถใช้แอป ทั้งนี้ไม่ตัดความรับผิดที่กฎหมายไม่อนุญาตให้ยกเว้น เช่น ความรับผิดจากการกระทำโดยจงใจหรือประมาทเลินเล่ออย่างร้ายแรง

8. การเปลี่ยนแปลงและการยุติ

เราอาจปรับปรุงแอปหรือข้อกำหนดนี้ หรือยุติการให้บริการได้ทุกเมื่อ หากข้อกำหนดเปลี่ยนแปลง จะแสดงวันที่มีผลใหม่ไว้ที่ด้านบน การใช้แอปต่อหลังจากนั้นถือว่าคุณยอมรับข้อกำหนดใหม่ คุณหยุดใช้แอปได้ทุกเมื่อโดยการออกจากระบบและยกเลิกสิทธิ์ที่ account.live.com/consent

9. กฎหมายที่ใช้บังคับ

ข้อกำหนดนี้อยู่ภายใต้กฎหมายแห่งราชอาณาจักรไทย
